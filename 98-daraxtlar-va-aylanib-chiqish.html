Daraxtlar: ierarxiya va uni aylanib chiqish

Bank tuzilmasi: bosh ofis → filiallar → bo‘limlar. Kompyuterdagi papkalar. HTML sahifa (DOM). JSON. PostgreSQL indeksi (B-tree). Hammasi — daraxt: har tugunning ota-onasi bitta, bolalari bir nechta bo‘lishi mumkin, sikl yo‘q. Bu darsda daraxtni "aylanib chiqish"ning 4 usulini ko‘ramiz — har biri o‘z masalasini yechadi.

01

Atamalar

Ildiz (root)Eng yuqoridagi tugun, ota-onasi yo‘q.
Barg (leaf)Bolasi yo‘q tugun.
Binary treeHar tugunda ko‘pi bilan 2 bola: left va right.
Chuqurlik (depth)Ildizdan tugungacha qirralar soni.
Balandlik (height)Ildizdan eng uzoq bargacha yo‘l.
Qism daraxt (subtree)Tugun va uning barcha avlodlari — o‘zi ham daraxt (shuning uchun rekursiya tabiiy!).
TreeNode.java
class TreeNode {
    int val;
    TreeNode left, right;      // ikkita bola (yoki null)
    TreeNode(int v) { val = v; }
}
02

DFS: chuqurlikka — pre, in, post

Uchala usul bir xil rekursiya, farqi faqat tugunni qachon "qayta ishlash"da: bolalardan oldin, orasida yoki keyin. Tartibni tanlang va natija qatoriga qarang.

Kirish:
DFS.java
  1. static void dfs(TreeNode n, List<Integer> out) {
  2. if (n == null) return;
  3. out.add(n.val); // PREORDER: ildiz → chap → o‘ng
  4. dfs(n.left, out);
  5. out.add(n.val); // INORDER: chap → ildiz → o‘ng
  6. dfs(n.right, out);
  7. out.add(n.val); // POSTORDER: chap → o‘ng → ildiz
  8. }
Preorder — nusxa olish, daraxtni satrga yozish (serializatsiya), papka tuzilmasini chop etish.
Inorder — BST’da saralangan tartib beradi (99-dars).
Postorder — avval bolalar: papka hajmini hisoblash, daraxtni o‘chirish, ifodani hisoblash.
Kodda uchta qator bor-u, bittasini ishlatamiz
Yuqoridagi kodda o‘qish oson bo‘lsin deb uchala joy ko‘rsatilgan — haqiqiy kodda faqat bittasi qoladi. Animatsiya tanlangan tartibga mos qatorni ishlatadi.
03

BFS: qavatma-qavat (navbat bilan)

Ildizdan boshlab avval 1-qavat, keyin 2-qavat… Buning uchun navbat (96-dars) kerak: tugunni olamiz, bolalarini navbat oxiriga qo‘yamiz.

Kirish:
BFS.java
  1. static List<Integer> bfs(TreeNode root) {
  2. List<Integer> out = new ArrayList<>();
  3. Deque<TreeNode> q = new ArrayDeque<>();
  4. if (root != null) q.offer(root);
  5. while (!q.isEmpty()) {
  6. TreeNode n = q.poll();
  7. out.add(n.val);
  8. if (n.left != null) q.offer(n.left);
  9. if (n.right != null) q.offer(n.right);
  10. }
  11. return out;
  12. }
04

Balandlikni hisoblash: postorder rekursiya

"Mening balandligim = 1 + bolalarimdan kattasi". Har tugun javobini bolalardan kutadi — postorder. Raqam ostida — tugun qaytargan qiymat.

Kirish:
Height.java
  1. static int height(TreeNode n) {
  2. if (n == null) return 0;
  3. int l = height(n.left);
  4. int r = height(n.right);
  5. return 1 + Math.max(l, r);
  6. }
05

Suhbat savollari

?DFS va BFS farqi? Qachon qaysi?›
DFS chuqurlikka (rekursiya yoki stek), xotira O(balandlik). BFS qavatma-qavat (navbat), xotira O(eng keng qavat). Eng qisqa yo‘l (og‘irliksiz) yoki qavatlar bo‘yicha masala — BFS; barcha yo‘llarni ko‘rish, backtracking, daraxt xossalari — DFS.
?Pre/in/post order qachon ishlatiladi?›
Pre — nusxalash, serializatsiya. In — BST’dan saralangan ro‘yxat, k-chi eng kichik element. Post — bolalar natijasi kerak bo‘lganda: balandlik, diametr, hajm, daraxtni o‘chirish.
?Rekursiyasiz inorder qanday yoziladi?›
Aniq stek bilan: chapga borguncha tugunlarni push; pop qilib qayta ishlaymiz; o‘ng bolaga o‘tamiz. O(n) vaqt, O(h) xotira. (Morris traversal — O(1) xotira, daraxtni vaqtincha o‘zgartiradi.)
?Daraxt balandligi va diametri?›
Balandlik = 1 + max(chap, o‘ng). Diametr (eng uzun yo‘l) = har tugunda chap + o‘ng balandliklar yig‘indisining maksimumi — bitta postorder o‘tishda.
?Ikki tugunning eng yaqin umumiy ajdodi (LCA)?›
Rekursiya: tugun null yoki p/q bo‘lsa — uni qaytar. Chap va o‘ngdan natija olamiz: ikkalasi ham null emas — joriy tugun LCA; aks holda null bo‘lmaganini qaytaramiz. O(n). BST’da qiymatlar bo‘yicha O(h).
?Daraxtda eng ko‘p qanday xatolar qilinadi?›
null tekshiruvini unutish, balandlik/chuqurlik chalkashligi, chuqur (zanjirsimon) daraxtda rekursiya StackOverflow, BFS’da qavat chegarasini (q.size()) aniqlamaslik.
