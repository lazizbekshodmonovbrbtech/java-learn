DOM va hodisalar

Brauzer HTML’ni o‘qib, DOM — obyektlar daraxtini quradi. JavaScript shu daraxtni o‘qiydi va o‘zgartiradi, foydalanuvchi harakatlariga (click, input, submit) javob beradi. Vue kabi framework’lar buni siz uchun qiladi — lekin ostida aynan shu mexanizmlar: hodisa tarqalishi, delegatsiya va XSS xavfi.

01

DOM daraxti

Chapda — oddiy to‘lov formasi, o‘ngda — uning DOM daraxti. Ikkala tomondagi elementni bosing — mos keladigani yonadi.

P2P o‘tkazma

dom.js
const forma = document.querySelector("#f");                 // CSS selektori bilan
const btn   = forma.querySelector(".btn-pay");
const inp   = document.querySelectorAll("input");            // NodeList (statik)

btn.textContent = "O'tkazish";                                // matn — xavfsiz
btn.classList.add("loading");                                 // class
btn.disabled = true;                                          // xossa
inp[1].value;                                                 // foydalanuvchi kiritgan qiymat (string!)

const li = document.createElement("li");                      // yangi element
li.textContent = "150 000 so'm — Dilnoza";
document.querySelector("#tarix").append(li);

    XSS orqali hujumchi skripti foydalanuvchi sessiyasida ishlaydi: token’ni o‘g‘irlaydi (localStorage’da bo‘lsa — oson), foydalanuvchi nomidan o‘tkazma yuboradi, sahifani soxtalashtiradi.     05
    Nega framework kerak?
    
    
    
      
    Qo‘lda DOM
    Holat o‘zgarsa — qaysi elementlarni yangilashni o‘zingiz eslab qolasiz. 20 ta joyda balans ko‘rsatilsa, 20 ta joyni yangilaysiz. Ketma-ket o‘qish/yozish (offsetHeight → style → offsetHeight…) — "layout thrashing", sekinlik. Listener’larni tozalash unutiladi — xotira sizishi.
    
      
    Deklarativ (Vue)
    Siz holatni o‘zgartirasiz (balans.value = 500), framework DOM’ning qaysi qismlari o‘zgarishini o‘zi hisoblab, eng kam o‘zgarish bilan yangilaydi (82-modul, reaktivlik). Listener’lar komponent bilan birga tozalanadi, matn avtomatik escape qilinadi.
    
    
    
  
    

  
    
    
    06
    Suhbat savollari
    ?DOM nima?›
    Document Object Model — HTML hujjatning brauzer xotirasidagi daraxt ko‘rinishi (tugunlar: element, matn, izoh…) va uni o‘qish/o‘zgartirish uchun API. HTML — matn, DOM — tirik obyektlar.
    ?Event bubbling va capturing nima?›
    Hodisa uch fazada tarqaladi: capture (window’dan target’gacha pastga), target, bubble (target’dan window’gacha yuqoriga). Listener default bubble’da; capture: true bilan capture’da. stopPropagation tarqalishni to‘xtatadi.
    ?Event delegation nima va nima uchun?›
    Ko‘p bolalar uchun bitta listener’ni ota elementga qo‘yish va e.target orqali manbani aniqlash. Kam xotira, dinamik qo‘shilgan elementlar ham ishlaydi. Bubbling tufayli mumkin.
    ?preventDefault va stopPropagation farqi?›
    preventDefault — brauzerning default harakatini bekor qiladi (forma yuborish, havola), hodisa tarqalishda davom etadi. stopPropagation — tarqalishni to‘xtatadi, default harakat bo‘ladi.
    ?innerHTML, textContent, innerText farqi?›
    innerHTML — HTML sifatida parse qiladi (XSS xavfi). textContent — xom matn, tez, yashirin elementlar matnini ham oladi. innerText — ko‘rinadigan matn, CSS’ni hisobga oladi (layout chaqiradi, sekinroq).
    ?e.target va e.currentTarget farqi?›
    target — hodisa haqiqatan sodir bo‘lgan eng ichki element; currentTarget — hozir ishlayotgan listener biriktirilgan element. Delegatsiyada currentTarget — ota, target — bosilgan bola.
