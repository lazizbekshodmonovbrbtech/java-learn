O‘zgaruvchilar va tiplar

Java’da int x = 5; — x abadiy int. JavaScript’da o‘zgaruvchining tipi yo‘q, qiymatning tipi bor. Bu erkinlik bilan birga tuzoqlar keladi: varning g‘alati ko‘lami, ==ning yashirin aylantirishlari, "truthy/falsy". Bu modulda ularni ko‘z bilan ko‘ramiz.

01

var, let, const

Qoida qisqa: default — const, qayta tayinlash kerak bo‘lsa — let, var — hech qachon. Nima uchun? Klassik misol: siklda taymer.

for (var i = 0; i < 3; i++) {
  setTimeout(() => console.log(i), 0);
}
let — har iteratsiyaga yangi quti
for (let i = 0; i < 3; i++) {
  setTimeout(() => console.log(i), 0);

06

Suhbat savollari

?var, let va const farqi?›
var — funksiya ko‘lami, hoisting bilan undefined, qayta e’lon qilinadi. let/const — blok ko‘lami, TDZ (e’londan oldin ReferenceError), qayta e’lon yo‘q. const — qayta tayinlab bo‘lmaydi, lekin obyekt/massiv ichini o‘zgartirish mumkin (Object.freeze — sayoz muzlatish).
?Hoisting nima?›
E’lonlar ko‘lam boshiga "ko‘tariladi": var — undefined bilan initsializatsiya qilinadi, function declaration — to‘liq (e’londan oldin chaqirish mumkin), let/const/class — ko‘tariladi, lekin TDZ tufayli e’longacha murojaat qilib bo‘lmaydi.
?== va === farqi?›
=== — tip va qiymat bir xil bo‘lsa true (NaN bundan mustasno). == — tiplar farq qilsa, Abstract Equality algoritmi bo‘yicha aylantiradi: null == undefined, son va satr → son, boolean → son, obyekt → primitiv. Natijalar intuitiv emas ("0" == false, [] == false), shuning uchun ===.
?JavaScript’da nechta tip bor?›
8: number, bigint, string, boolean, undefined, null, symbol (primitivlar) va object. Massiv, funksiya, Date — object turlari.
?null va undefined farqi?›
undefined — qiymat berilmagan (e’lon qilingan o‘zgaruvchi, yo‘q xossa, qaytarmagan funksiya). null — dasturchi ataylab qo‘ygan "bo‘sh qiymat". API’da ko‘pincha null. ?? operatori ikkalasini ham "yo‘q" deb qaraydi.
?|| va ?? farqi?›
|| — chap tomon falsy bo‘lsa (0, "", false ham) o‘ngni qaytaradi. ?? — faqat null/undefined bo‘lsa. Balans 0 bo‘lsa: balance || "noma’lum" → "noma’lum" (xato!), balance ?? "noma’lum" → 0.
