Funksiya, scope va closure

JavaScript’da funksiya — oddiy qiymat: uni o‘zgaruvchiga saqlash, argument qilib berish, boshqa funksiyadan qaytarish mumkin. Bundan closure kelib chiqadi — funksiya o‘zi yaratilgan muhitni "eslab qoladi". Vue’ning composable’lari, event handler’lar, debounce — hammasi closure ustida. Va this — Java’dan eng ko‘p farq qiladigan joy.

01

Funksiya yozishning uch shakli

funksiyalar.js
// 1) declaration — hoisting bilan (e'londan oldin chaqirish mumkin)
function foiz(summa, stavka) { return summa * stavka / 100; }

// 2) expression — o'zgaruvchiga qiymat sifatida
const komissiya = function (summa) { return Math.max(1000, summa * 0.005); };

// 3) arrow — qisqa, O'Z this'i YO'Q (tashqaridan oladi)
const qqs = summa => summa * 0.12;
const format = (s, val = "UZS") => `${s.toLocaleString("ru-RU")} ${val}`;

// Yuqori tartibli funksiya (Java: Function<Long, Long>)
const qollash = (f, x) => f(x);
qollash(qqs, 100000);            // 12000

04

this: kim chaqirdi?

Java’da this — doim joriy obyekt. JS’da this funksiya qanday chaqirilganiga bog‘liq (arrow bundan mustasno). Chaqiruv usulini tanlang.

kassa.js
"use strict";
const kassa = {
  nomi: "Chilonzor-3",
  salom() { return this?.nomi; },          // oddiy metod
  salomArrow: () => this?.nomi,            // arrow — this tashqaridan (modul: undefined)
  kechikib() { setTimeout(function () { log(this?.nomi); }, 0); },
  kechikibArrow() { setTimeout(() => log(this.nomi), 0); },
};

06

Suhbat savollari

?Closure nima?›
Funksiya va u yaratilgan leksik muhitning (tashqi o‘zgaruvchilarga havolalar) birikmasi. Tashqi funksiya tugagandan keyin ham ichki funksiya o‘sha o‘zgaruvchilarni ko‘radi va o‘zgartiradi, chunki muhit heap’da, closure unga havola saqlaydi.
?Closure qayerda ishlatiladi?›
Ma’lumotni yashirish (module pattern, fabrika funksiyalar), callback’lar va event handler’lar, currying/partial application, memoization, debounce/throttle, once(), Vue composable’lari va React hook’lari.
?Closure xotira sizishiga sabab bo‘lishi mumkinmi?›
Ha: closure ushlab turgan muhit (masalan, katta massiv) funksiya yashar ekan GC qilinmaydi. Tipik holat — o‘chirilmagan event listener yoki setInterval katta obyektni ushlab turadi. Yechim: listener’ni olib tashlash, clearInterval, Vue’da onUnmounted’da tozalash.
?this qanday aniqlanadi?›
Chaqiruv usuli bo‘yicha: obj.f() → obj; oddiy f() → undefined (strict); new → yangi obyekt; call/apply/bind → berilgan qiymat. Arrow funksiyaning o‘z this’i yo‘q — tashqi ko‘lamdan oladi. Metodni callback qilib bersangiz (setTimeout(obj.f)) this yo‘qoladi.
?Arrow va oddiy funksiya farqi?›
Arrow: o‘z this, arguments, super, new.target yo‘q; konstruktor bo‘lolmaydi; qisqa sintaksis. Oddiy funksiya: dinamik this, arguments, new bilan chaqirish mumkin. Obyekt metodlari uchun — oddiy (yoki qisqa metod sintaksisi), callback’lar uchun — arrow.
?Java lambda va JS closure farqi?›
Java lambda tashqi lokal o‘zgaruvchilarni faqat effectively final bo‘lsa qamraydi (qiymat nusxasi kabi). JS closure o‘zgaruvchining o‘zini (bog‘lanishni) qamraydi — o‘qiydi va o‘zgartiradi; shuning uchun var+sikl tuzog‘i (66-modul).
