Massivlar (arrays)

Bir tipdagi ko'p qiymatni bitta o'zgaruvchida saqlash. Massiv — xotirada yonma-yon turadigan qutilar, har biriga indeks (0 dan boshlanadi) orqali kirasiz. Kolleksiyalar (14-modul) ham shundan quriladi.

01

Massiv — indekslangan qutilar

Massiv 6 ta sonni saqlaydi. Har qutiga indeks orqali kirasiz — muhimi: indeks 0 dan boshlanadi, oxirgisi length−1. Katakni bosing yoki "Yur"ni bosing — arr[i] qaysi qutiga tegishini kuzating.

int[] arr = {50, 20, 80, 10, 60, 30};
0 dan boshlanadi
Birinchi element — arr[0], oltinchi (oxirgi) — arr[5]. 6 elementli massivda arr[6] yo'q — bu eng ko'p uchraydigan xato manbasi (keyingi bo'limda ko'ramiz).
02

Massiv xotirada qanday turadi

Massiv — reference tip (3-modul). O'zgaruvchi Stack'da, lekin haqiqiy elementlar Heap'da yonma-yon (ketma-ket) bloklarda. Aynan shu ketma-ketlik tufayli arr[i] juda tez — Java to'g'ridan-to'g'ri manzilni hisoblaydi (o(1)).

arr → 0x9A00 (Heap manzili)
↓ ko'rsatadi
50
20
80
10
60
30
Heap: yonma-yon 6 ta int, boshlanish manzili 0x9A00
nega tez
arr[3] = boshlanish manzili + 3 × (element o'lchami). Bitta hisob — shuning uchun massivda istalgan indeksga kirish bir xil tezlikda (O(1)), qidirishsiz.
03

E'lon qilish usullari

Arrays.java
// 1) qiymatlar bilan darhol
int[] a = {50, 20, 80};

// 2) o'lcham berib (default qiymatlar bilan to'ladi)
int[] b = new int[5];     // {0, 0, 0, 0, 0}
String[] c = new String[3]; // {null, null, null}
boolean[] d = new boolean[2]; // {false, false}

// keyin to'ldirish:
b[0] = 100;
b[1] = 200;
default qiymatlar
new int[5] avtomatik 0 bilan to'ladi (double→0.0, boolean→false, obyektlar→null). Massiv o'lchami o'zgармaydi — bir marta belgilangач qat'iy.
04

ArrayIndexOutOfBounds — sindirib ko'ring

Java'da eng ko'p uchraydigan runtime xatolaridan biri. Massiv chegarasidan tashqaridagi indeksga tegsangiz — dastur qulaydi. Quyidagi indekslardan birini bosing. 0–4 to'g'ri, 5 va −1 esa xatoni haqiqatan keltiradi.

Indeksni bosing. 0–4 ishlaydi; 5 yoki −1 ni bosib xatoni ko'ring.
himoya
Siklda doim i < arr.length ishlating (<= emas!). Bu klassik "off-by-one" xatosi — <= yozsangiz oxirgi qadamda chegaradan chiqib qulaydi.
05

Ko'p o'lchovli massiv (jadval)

Massiv ichida massiv — jadval kabi. arr[qator][ustun]. Katakni bosing — qaysi [qator][ustun] ekanini ko'ring.

Katakni bosing
Grid.java
int[][] jadval = {
    {1, 2, 3},   // qator 0
    {4, 5, 6},   // qator 1
    {7, 8, 9}    // qator 2
};
jadval[1][2]  // qator 1, ustun 2 → 6

Arrays yordamchisi va for-each

java.util.Arrays massivlar bilan ishlashni osonlashtiradi. Va indeks kerak bo'lmasa — for-each tozaroq.

ForEach.java
// klassik for — indeks kerak bo'lsa
for (int i = 0; i < arr.length; i++) {
    System.out.println(i + ": " + arr[i]);
}
// for-each — faqat qiymat kerak bo'lsa (tozaroq)
for (int son : arr) {
    System.out.println(son);
}
tuzoq
Massivda length — maydon (qavssiz: arr.length). String'da esa length() — metod (qavs bilan). Ko'p adashadi.
07

Massiv vs ArrayList

Massivning katta cheklovi — o'lchami qat'iy. Amalda ko'proq ArrayList (14-modul) ishlatiladi, chunki u o'zi kengayadi.

Array (int[])

  • O'lcham qat'iy — o'zgarmaydi
  • Primitivlarni ham saqlaydi
  • Biroz tezroq, kam xotira
  • arr[i], arr.length

ArrayList

  • O'zi kengayadi (dinamik)
  • Faqat obyektlar (Integer)
  • add/remove/size metodlari
  • Amalda ko'proq ishlatiladi
08

Suhbat savollari

?Massiv indeksi nechadan boshlanadi va nega?
0 dan. Indeks aslida "boshidan qancha uzoqda" degani. Birinchi element boshida turadi — siljish 0. arr[i] = boshlanish manzili + i × o'lcham. Shuning uchun oxirgi indeks length−1.
?Nega array'ga kirish O(1)?
Elementlar xotirada yonma-yon (contiguous) turadi. Istalgan arr[i] manzili bitta matematik amal bilan hisoblanadi — qidirishning hojati yo'q. Shuning uchun indeksga kirish doim bir xil, tez.
?Array vs ArrayList qachon qaysi?
O'lcham oldindan ma'lum va qat'iy bo'lsa, yoki primitivlar bilan tezlik/xotira muhim bo'lsa — array. Elementlar soni o'zgarib tursa (qo'shish/o'chirish) — ArrayList, chunki u o'zi kengayadi. Amalda ko'proq ArrayList.
?new int[3] nima bilan to'ladi?
Default qiymatlar bilan: son tiplari → 0, boolean → false, obyektlar (String, ...) → null. null'li obyekt massivini ishlatishda ehtiyot bo'ling — NullPointerException chiqishi mumkin.
