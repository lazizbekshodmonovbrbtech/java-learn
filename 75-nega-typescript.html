Nega TypeScript?

Java dasturchi uchun JavaScript’dagi eng og‘riqli narsa — kompilyator yo‘qligi: xato faqat ishlaganda, ko‘pincha production’da chiqadi. TypeScript — JS ustidagi tip qatlami: kod yozayotganingizda IDE xatoni qizil chiziq bilan ko‘rsatadi, build esa uni o‘tkazmaydi. Vue 3 ekotizimi deyarli to‘liq TS’da. Bu trek sizga u yerda o‘zingizni Java’dagidek ishonchli his qilishni o‘rgatadi.

🎯 Java bilan o‘xshashlik va farq
Java’da ham generics o‘chiriladi (type erasure: List<String> → List), lekin klasslar, instanceof va maydon tiplari runtime’da bor. TS’da hech narsa qolmaydi: interface runtime’da yo‘q, x instanceof Tolov interfeys bilan ishlamaydi. Backend’dan kelgan JSON TS aytganidek bo‘lishiga kafolat yo‘q — shuning uchun chegarada runtime validatsiya (zod, 79-modul).

06
Suhbat savollari
?TypeScript nima va nima uchun kerak?›
JS’ning ustki to‘plami (superset) bo‘lgan tilga statik tiplar qo‘shadigan til va kompilyator. Xatolarni erta (IDE, build) topadi, refaktoring va avtoto‘ldirishni ishonchli qiladi, kodni hujjatlaydi. Natija — oddiy JS; runtime xulqni o‘zgartirmaydi.
?TypeScript runtime’da tiplarni tekshiradimi?›
Yo‘q. Tiplar kompilyatsiyada o‘chiriladi. API javobi, localStorage, foydalanuvchi kiritishi kabi tashqi ma’lumotni runtime’da tekshirish uchun zod/valibot kabi validatorlar kerak.
?strict rejim nimalarni yoqadi?›
strictNullChecks, noImplicitAny, strictFunctionTypes, strictBindCallApply, strictPropertyInitialization, noImplicitThis, alwaysStrict, useUnknownInCatchVariables. Yangi loyihada — albatta yoqiq.
?any va unknown farqi?›
any — tekshiruvni butunlay o‘chiradi (har narsa mumkin, xato yuqumli tarqaladi). unknown — xavfsiz "noma’lum": ishlatishdan oldin tipni toraytirish (typeof, instanceof, validator) shart. Tashqi ma’lumot uchun unknown.
?TS’ni mavjud JS loyihaga qanday kiritasiz?›
Bosqichma-bosqich: allowJs + checkJs yoki JSDoc tiplar, fayllarni birma-bir .ts ga o‘tkazish, avval strict’siz, keyin flag’larni birin-ketin yoqish, API chegarasidagi tiplardan boshlash (DTO’lar — OpenAPI’dan generatsiya, 79-modul).
