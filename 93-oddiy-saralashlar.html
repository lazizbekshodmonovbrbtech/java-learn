Oddiy saralashlar: bubble, selection, insertion

Kartalarni qo‘lda qanday tartiblaysiz? Ehtimol, har birini olib, chap qo‘lingizdagi tartiblangan kartalar orasiga to‘g‘ri joyiga qo‘yasiz — bu insertion sort. Bu darsda uchta "intuitiv" saralashni ustunlar harakatida ko‘ramiz, taqqoslash va almashtirishlarni sanaymiz va nega ularning hammasi O(n²) ekanini tushunamiz.

01

Bubble sort: kattalar "suzib" chiqadi

Qo‘shni ikkitasini solishtiramiz; tartibsiz bo‘lsa — almashtiramiz. Bitta o‘tishda eng kattasi oxiriga "suzib" chiqadi (yashil — o‘z joyida).

Kirish:
BubbleSort.java
  1. static void bubble(int[] a) {
  2. for (int i = 0; i < a.length - 1; i++) {
  3. boolean almashdi = false;
  4. for (int j = 0; j < a.length - 1 - i; j++) {
  5. if (a[j] > a[j + 1]) {
  6. int t = a[j]; a[j] = a[j + 1]; a[j + 1] = t;
  7. almashdi = true;
  8. }
  9. }
  10. if (!almashdi) break; // tartibda — erta chiqish
  11. }
  12. }
02

Selection sort: eng kichigini tanla

Har o‘tishda qolgan qismdan eng kichigini topib, uni chegaraga qo‘yamiz. Almashtirishlar kam (n−1 tadan oshmaydi), lekin taqqoslashlar doim ko‘p.

Kirish:
SelectionSort.java
  1. static void selection(int[] a) {
  2. for (int i = 0; i < a.length - 1; i++) {
  3. int min = i;
  4. for (int j = i + 1; j < a.length; j++) {
  5. if (a[j] < a[min]) min = j;
  6. }
  7. int t = a[i]; a[i] = a[min]; a[min] = t;
  8. }
  9. }
03

Insertion sort: qo‘ldagi kartalar kabi

key — qo‘limizdagi yangi karta. Chapdagi tartiblangan qismda undan kattalarni o‘ngga surib, bo‘shagan joyga qo‘yamiz.

Kirish:
InsertionSort.java
  1. static void insertion(int[] a) {
  2. for (int i = 1; i < a.length; i++) {
  3. int key = a[i];
  4. int j = i - 1;
  5. while (j >= 0 && a[j] > key) {
  6. a[j + 1] = a[j]; // o‘ngga surish
  7. j--;
  8. }
  9. a[j + 1] = key;
  10. }
  11. }
Insertion sort — "oddiy" lekin foydali
Deyarli saralangan ma’lumotda O(n) ga yaqin ishlaydi va kichik massivlarda (≲ 32 element) murakkab algoritmlardan tezroq. Shuning uchun Java’ning Arrays.sort (obyektlar uchun TimSort) kichik bo‘laklarni aynan insertion sort bilan saralaydi (94-dars).

06

Suhbat savollari

?Bubble, selection va insertion sort farqi?›
Bubble — qo‘shnilarni almashtirib, kattalarni oxiriga suzdiradi. Selection — har safar minimumni tanlab chegaraga qo‘yadi (almashtirish kam, taqqoslash doim n²/2). Insertion — har elementni tartiblangan prefiks ichiga joylaydi (deyarli saralangan ma’lumotda O(n)). Uchalasi ham o‘rtacha O(n²), xotira O(1).
?Barqaror saralash nima va qachon muhim?›
Teng kalitli elementlarning nisbiy tartibi saqlanadi. Ko‘p bosqichli saralashda muhim: avval sana bo‘yicha, keyin summa bo‘yicha — teng summalar sana tartibida qoladi. Java’da Collections.sort/List.sort va Arrays.sort(Object[]) barqaror (TimSort); primitivlar uchun Arrays.sort barqaror emas (lekin primitivlarda farqi ko‘rinmaydi).
?Insertion sort qachon eng yaxshi tanlov?›
n kichik (o‘nlab element) yoki ma’lumot deyarli saralangan (inversiyalar soni kam) — ish hajmi O(n + inversiyalar). Shuning uchun TimSort va introsort kichik bo‘laklarda insertion sort ishlatadi. Shuningdek "onlayn" — elementlar kelishi bilan saralash mumkin.
?Taqqoslashga asoslangan saralashning pastki chegarasi?›
Ω(n log n) — n! ta tartibni ajratish uchun qaror daraxti balandligi log₂(n!) ≈ n log n. Shuning uchun merge/heap/quick sort optimal; tezroq faqat taqqoslamaydigan algoritmlar (counting, radix) — ma’lumot cheklangan bo‘lsa (94-dars).
