Reaktivlik: Vue qanday "biladi"?

Vue’da balans.value = 500 yozasiz — ekranda balans, USD ekvivalenti va limit ogohlantirishi o‘zi yangilanadi, qolgan joylar esa tegilmaydi. Qanday qilib? Har render paytida Vue qaysi komponent qaysi holatni o‘qiganini yozib oladi (track), holat o‘zgarganda esa faqat o‘shalarni qayta ishga tushiradi (trigger). Bu mexanizm JavaScript Proxy ustida qurilgan — quyida uning ishlayotgan nusxasi.

01

Bog‘liqliklar grafi — jonli

Chapda — holat, o‘rtada — computed, o‘ngda — "komponentlar" (effect’lar). Chiziqlar render paytida avtomatik paydo bo‘ldi — hech kim ularni qo‘lda yozmadi. Holatni o‘zgartiring va to‘lqin qaysi yo‘ldan ketishini kuzating.

BalansKarta render: 1KursLenta render: 1LimitBelgi render: 1usd qayta hisob: 1
Boshlang‘ich render: har effect ishga tushdi va o‘qigan holatlari "track" qilindi (chiziqlar).
reactivity (soddalashtirilgan — sahifadagi dvigatel aynan shunday)
function reactive(obj) {
  return new Proxy(obj, {
    get(t, key) { track(t, key); return t[key]; },              // kim o'qiyapti? — yozib ol
    set(t, key, v) { t[key] = v; trigger(t, key); return true; } // kim o'qigan edi? — qayta ishga tushir
  });
}
let activeEffect = null;
function effect(fn) { activeEffect = fn; fn(); activeEffect = null; }   // render = effect
// track:   deps[t][key].add(activeEffect)
// trigger: deps[t][key].forEach(e => e())

05

Suhbat savollari

?Vue 3 reaktivligi qanday ishlaydi?›
reactive/ref Proxy (ref — getter/setter) orqali. Effect (render, computed, watch) ishlaganda o‘qilgan har xossa track qilinadi: target → key → effect’lar to‘plami (WeakMap/Map/Set). Xossa o‘zgarganda trigger shu effect’larni scheduler orqali qayta ishga tushiradi. Natija — nozik (fine-grained) bog‘liqlik: faqat kerakli komponentlar qayta render bo‘ladi.
?Vue 2 va Vue 3 reaktivligi farqi?›
Vue 2: Object.defineProperty — yangi xossa qo‘shish va massiv indeksi bilan o‘zgartirish sezilmasdi (Vue.set kerak edi). Vue 3: Proxy — qo‘shish, o‘chirish, indeks, Map/Set hammasi seziladi, dangasa (faqat o‘qilganda) chuqur proxy.
?ref va reactive farqi, qaysi birini tanlaysiz?›
ref — har qanday qiymat, .value orqali, almashtirish mumkin; reactive — faqat obyekt, .value yo‘q, destructuring va almashtirishda reaktivlik yo‘qoladi. Vue jamoasi tavsiyasi — asosan ref.
?computed va watch farqi?›
computed — sof hosila qiymat, keshlanadi, faqat bog‘liqlik o‘zgarsa va o‘qilganda qayta hisoblanadi. watch — yon ta’sir uchun (API, log, storage), qiymat qaytarmaydi, eski/yangi qiymatni beradi, immediate/deep/once opsiyalari.
?nextTick nima uchun kerak?›
Vue DOM yangilanishlarini microtask’da batch qiladi. Holatni o‘zgartirgandan keyin darhol yangilangan DOM’ni o‘qish (o‘lcham, fokus) kerak bo‘lsa — await nextTick().
?Katta ro‘yxat (10 000 element) sekin. Reaktivlik tomonidan nima qilish mumkin?›
shallowRef (chuqur proxy yaratmaslik), markRaw, faqat ko‘rinadigan qismni render (virtual scroll), v-memo, kalitlarni to‘g‘ri berish, computed’larni keshlash.
