05
Suhbat savollari
?Narrowing nima?›
Kompilyatorning control flow tahlili: typeof, instanceof, in, tenglik, truthiness tekshiruvlari va return/throw’dan keyin o‘zgaruvchining tipini toraytiradi. Masalan, if (x !== null) blokida x: string.
?Union va intersection tiplar?›
Union A | B — qiymat A yoki B (ishlatishdan oldin toraytirish kerak). Intersection A & B — qiymat ikkalasining ham xossalariga ega (obyektlarni birlashtirish).
?Discriminated union nima va nega foydali?›
Umumiy literal maydonli (tur: "ok" | "xato") union. switch/if bilan har variant aniq toraytiriladi, never bilan hamma holatlar ko‘rib chiqilganini kompilyator kafolatlaydi. API javoblari, holat mashinalari, Redux action’lari uchun.
?never tipi qayerda ishlatiladi?›
Bo‘sh tip: hech qachon qaytmaydigan funksiya (throw), toraytirishdan keyin qolgan "imkonsiz" holat (exhaustiveness check), conditional tiplarda filtrlash.
?enum yoki union literal?›
Union literal ("UZS" | "USD") — runtime kodi yo‘q, tree-shake, JSON bilan to‘g‘ridan-to‘g‘ri mos. enum — runtime obyekt, raqamli enum’lar xavfli (har qanday son mos keladi). Ko‘p jamoalar union yoki as const obyektni afzal ko‘radi.
?as (type assertion) qachon xavfli?›
as — kompilyatorga "menga ishon" deyish, runtime tekshiruv yo‘q. Noto‘g‘ri bo‘lsa xato keyin, boshqa joyda chiqadi. Imkon qadar narrowing yoki validator; as const va as unknown as T — faqat ongli holda.
