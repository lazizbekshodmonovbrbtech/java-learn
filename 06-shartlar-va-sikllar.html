for (int i = 1; i <= 6; i++) {
    if (i == 3) continue;  // 3 ni tashla, davom et → 1,2,4,5,6
    // yoki: if (i == 3) break;  // 3 da butunlay to'xta → 1,2

05

Sikl turlari

To'rt xil sikl. Qaysi birini tanlash — vaziyatga bog'liq.

for

Sanoqli takror (aniq necha marta)

for(int i=0; i<n; i++)

while

Shart to'g'ri ekan takrorlaydi (necha marta noma'lum)

while(shart) { ... }

do-while

Kamida bir marta ishlaydi, keyin shartni tekshiradi

do { ... } while(shart);

for-each

Kolleksiya/massiv bo'ylab, indekssiz

for(int x : arr) { ... }
while vs do-while
while avval shartni tekshiradi — 0 marta ishlashi mumkin. do-while avval tanani bajaradi — kamida 1 marta ishlaydi. "Menyuni kamida bir marta ko'rsat, keyin chiqishni so'ra" — do-while uchun ideal.

07
Suhbat savollari

    

      
?break va continue farqi?
break — sikldan butunlay chiqadi. continue — joriy takrorni tashlab, keyingisiga o'tadi (sikl davom etadi). break to'xtatadi, continue o'tkazib yuboradi.

      
?while va do-while qachon qaysi?
while — shartni avval tekshiradi, 0 marta ishlashi mumkin. do-while — tanani avval bajaradi, kamida 1 marta ishlaydi. Foydalanuvchiga menyuni kamida bir marta ko'rsatish kerak bo'lsa — do-while.

      
?Cheksiz sikl (infinite loop) qanday yuz beradi?
Shart hech qachon yolg'on bo'lmasa: while(true), yoki forda i++ni unutish, yoki shartni noto'g'ri yozish. Dastur qotib qoladi. Ba'zan while(true) { ... break; } ataylab ishlatiladi.

      
?Zamonaviy switch nima yaxshi?
-> sintaksisi: break kerak emas (fall-through xatosi yo'q), va butun switch qiymat qaytaradi. Eski switch'da break unutish keyingi case'ga "oqib" o'tishga sabab bo'lardi — bu mashhur xato.
