Obyekt va massivlar

JS’da obyekt — kalit-qiymat lug‘ati (Java’dagi Map<String,Object> + klasssiz obyekt), massiv — dinamik ro‘yxat (ArrayList). Backend’dan kelgan JSON bilan ishlashning 90%i — shu ikkisi: destructuring, spread va map/filter/reduce. Java Stream’ni bilsangiz, yarmi tanish.

01

Obyekt sintaksisi: qisqa yozuvlar

obyektlar.js
const summa = 150000, valyuta = "UZS";
const tolov = {
  id: "p-1",
  summa,                            // shorthand: summa: summa
  valyuta,
  ["tur_" + 1]: "P2P",              // hisoblangan kalit
  qabulQiluvchi: { ism: "Dilnoza", karta: "8600****1234" },
  format() { return `${this.summa} ${this.valyuta}`; },   // metod
};

// Destructuring — Java'da yo'q (record pattern'dan tashqari)
const { id, summa: s, komissiya = 0, qabulQiluvchi: { ism } } = tolov;
//        ↑     ↑ qayta nomlash  ↑ default          ↑ ichma-ich

// Optional chaining — NullPointerException'siz
tolov.yuboruvchi?.karta?.oxirgi4 ?? "—";      // "—"

const [birinchi, , uchinchi, ...qolgan] = [10, 20, 30, 40, 50];  // massiv destructuring

Java kabi, JS’da obyekt o‘zgaruvchisi — havola. Nusxa usulini tanlang, keyin b.manzil.shahar ni o‘zgartiring — a ga nima bo‘ladi?

⚠️ Vue va React uchun muhim
Frontend framework’lar o‘zgarishni ko‘pincha havola orqali sezadi. Sayoz nusxada ichki obyekt umumiy qoladi — uni o‘zgartirsangiz "eski holat" ham o‘zgaradi (undo, form reset buziladi). Immutable yangilash: { ...a, manzil: { ...a.manzil, shahar: "Samarqand" } }.

06
Suhbat savollari
?Sayoz va chuqur nusxa farqi? Qanday qilinadi?›
Sayoz: faqat yuqori darajadagi xossalar nusxalanadi, ichki obyektlar umumiy havola ({...a}, Object.assign, arr.slice()). Chuqur: butun daraxt nusxalanadi — structuredClone(a) (Date, Map, Set’ni ham to‘g‘ri; funksiyalarni emas), JSON.parse(JSON.stringify(a)) (Date → string, undefined yo‘qoladi — tavsiya etilmaydi).
?map, filter, reduce, forEach farqi?›
map — har elementni o‘zgartirib yangi massiv (bir xil uzunlik); filter — shartga mos elementlar; reduce — bitta qiymatga yig‘ish; forEach — faqat yon ta’sir, hech narsa qaytarmaydi, break yo‘q (for…of ishlating).
?Qaysi massiv metodlari massivni o‘zgartiradi?›
push, pop, shift, unshift, splice, sort, reverse, fill, copyWithin. O‘zgartirmaydiganlar: map, filter, slice, concat, toSorted, toReversed, toSpliced, with. Vue/React’da state’ni immutable yangilash kerak bo‘lsa — ikkinchi guruh.
?Destructuring va spread nima?›
Destructuring — obyekt/massivdan qiymatlarni o‘zgaruvchilarga ajratish (nomlash, default, ichma-ich). Spread (...) — massiv/obyektni yoyish: nusxa, birlashtirish, argumentlarga berish. Rest (...) — qolganlarini yig‘ish.
?Obyekt va Map farqi?›
Obyekt kalitlari — faqat string/symbol, prototipdan meros kalitlar bo‘lishi mumkin, tartib qoidalari murakkab. Map — istalgan tipdagi kalit (obyekt ham), qo‘shilish tartibi, size, tez-tez qo‘shish/o‘chirish uchun optimallashgan. JSON uchun — obyekt; lug‘at/kesh uchun — Map.
?JSON.stringify’ning tuzoqlari?›
undefined va funksiyalar tashlab yuboriladi, Date ISO satrga aylanadi (parse’da Date bo‘lib qaytmaydi), BigInt xato beradi, NaN/Infinity → null, aylanma havola — xato. Katta son ID’lar precision yo‘qotadi (66-modul).
