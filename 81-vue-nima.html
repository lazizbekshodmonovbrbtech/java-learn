      06

      Suhbat savollari

      ?Vue nima va qanday muammoni hal qiladi?›
      Deklarativ, komponentli UI framework: holat va shablon beriladi, DOM’ni sinxronlash (qaysi element qachon yangilanadi) Vue’ning ishi. Reaktivlik tizimi bog‘liqliklarni avtomatik kuzatadi, komponentlar kodni qayta ishlatish va izolyatsiya qilish imkonini beradi.
      ?Deklarativ va imperativ UI farqi?›
      Imperativ — "qanday": DOM’ni qadamma-qadam o‘zgartirish buyruqlari (createElement, textContent). Deklarativ — "nima": UI holatdan qanday ko‘rinishi kerakligi tasvirlanadi, o‘tishni framework bajaradi. Imperativda holat va UI bir-biridan uzilib qolishi (stale UI) oson.
      ?Virtual DOM nima? Vue uni qanday ishlatadi?›
      DOM’ning yengil JS nusxasi: yangi render natijasi eskisi bilan solishtirilib (diff), faqat farqlar haqiqiy DOM’ga qo‘llanadi. Vue kompilyatori shablondagi statik qismlarni belgilaydi (static hoisting, patch flags) — diff tezroq. Vapor mode (tajribaviy) virtual DOM’siz to‘g‘ridan-to‘g‘ri yangilash yo‘nalishi.
      ?SFC nima?›
      Single File Component: .vue fayl — template, script (setup), style (scoped) bir joyda. Vite plugin’i uni JS render funksiyasiga kompilyatsiya qiladi.
      ?Options API va Composition API?›
      Options API — data, methods, computed, watch bo‘limlari (Vue 2 uslubi). Composition API — setup ichida ref/computed/watch funksiyalari, mantiqni composable’larga ajratish oson, TS bilan yaxshi. Yangi loyihalar — <script setup> + Composition API (85-modul).
