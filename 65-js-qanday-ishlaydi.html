JavaScript qanday ishlaydi

Java dasturchi uchun JavaScript tanish ko‘rinadi — if, for, class… lekin ostida butunlay boshqa dunyo: dinamik tiplar, prototiplar, bitta ip va event loop. Bu trek sizni Vue/TypeScript bilan frontend yozishga va Keycloak’li SPA’larni tushunishga tayyorlaydi. Avval: JS kodi qayerda va qanday bajariladi?

06

Suhbat savollari

?JavaScript interpretatsiya qilinadigan tilmi yoki kompilyatsiya qilinadigan?›
Zamonaviy dvigatellarda ikkalasi: manba kod parse qilinib bytecode’ga aylanadi va interpretator bajaradi, issiq kod JIT bilan mashina kodiga kompilyatsiya qilinadi (V8: Ignition → Sparkplug/Maglev → TurboFan). Tip taxminlari buzilsa — deoptimizatsiya.
?JavaScript bitta ipli bo‘lsa, qanday qilib bir vaqtda ko‘p ish qiladi?›
Asosiy ip bitta, lekin I/O (tarmoq, taymer, fayl) brauzer/Node tomonidan fonda bajariladi; tayyor bo‘lgach callback navbatga tushadi va event loop uni bo‘sh paytda asosiy ipda bajaradi. Og‘ir hisob-kitob uchun Web Worker’lar (70-modul).
?async va defer farqi?›
Ikkalasi ham skriptni parallel yuklaydi, parser to‘xtamaydi. async — yuklangan zahoti bajariladi (tartib kafolatlanmaydi, DOM tayyor bo‘lmasligi mumkin) — analitika kabi mustaqil skriptlar uchun. defer — HTML to‘liq parse qilingach, hujjatdagi tartibda, DOMContentLoaded’dan oldin bajariladi. type="module" default holatda defer kabi.
?0.1 + 0.2 nega 0.30000000000000004?›
JS’da barcha sonlar IEEE 754 double (Java’dagi double kabi). 0.1 ikkilik sanoqda aniq ifodalanmaydi. Pul uchun: tiyinlarda butun son, BigInt yoki decimal kutubxona; ko‘rsatishda Intl.NumberFormat. Java’dagi BigDecimal muammosi bilan bir xil.
?ECMAScript va JavaScript farqi?›
ECMAScript — standart (spetsifikatsiya), JavaScript — uning eng mashhur implementatsiyasi (+ brauzer API’lari: DOM, fetch, taymerlar — bular ECMAScript’ga kirmaydi).
