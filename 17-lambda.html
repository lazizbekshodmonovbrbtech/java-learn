Lambda va funksional interfeyslar

Java 8'ning inqilobi: kodni qiymat sifatida uzatish. Ilgari "bir marta ishlatiladigan xatti-harakat" uchun butun class yozilardi — endi bitta qator. Stream API (18-modul) shunga quriladi.

01

Anonymous class'dan lambda'ga — qadam-baqadam

Lambda sehr emas — u anonymous class'ning qisqa yozuvi. Kompilyator ortiqcha narsalarni o'zi "topib oladi". Har qadamda nima olib tashlanishini kuzating.

lambda ishlashi uchun shart
Lambda faqat functional interfacega tayinlanadi — aynan bitta abstract metodi bo'lgan interfeys. Shunda kompilyator qaysi metodni amalga oshirayotganingizni bilib oladi.
02

Tayyor funksional interfeyslar — sinab ko'ring

Java java.util.functionda ko'p ishlatiladiganlarini tayyor beradi. Har biri "qancha kirish, qanday chiqish" bilan farq qiladi. Birini tanlang, qiymat kiriting, natijani ko'ring.

03

Method reference — yanada qisqa

Lambda faqat mavjud metodni chaqirsa, uni :: bilan yanada qisqartirsa bo'ladi.

MethodRef.java
// lambda → method reference
s -> System.out.println(s)     →   System.out::println
s -> s.toUpperCase()           →   String::toUpperCase
x -> new User(x)               →   User::new

// amalda:
ismlar.forEach(System.out::println);
ismlar.stream().map(String::toUpperCase);
04

O'z funksional interfeysingiz

Custom.java
@FunctionalInterface   // kompilyator: faqat 1 abstract metod bo'lsin
interface Hisoblagich {
    int hisobla(int a, int b);
}

Hisoblagich qoshish = (a, b) -> a + b;
Hisoblagich kopaytir = (a, b) -> a * b;
qoshish.hisobla(3, 4);    // 7
kopaytir.hisobla(3, 4);  // 12 — bir interfeys, turli xatti-harakat
effectively final
Lambda tashqi lokal o'zgaruvchini ishlatsa, u o'zgarmas (final yoki effectively final) bo'lishi shart. int n = 5; Runnable r = () -> print(n); n = 6; — xato! Sabab: lambda o'zgaruvchining nusxasini oladi.
05

Suhbat savollari

?Lambda nima va nega kerak?
Nomsiz funksiya — xatti-harakatni qiymat sifatida uzatish usuli. Anonymous class'ning qisqa yozuvi. Foydasi: kamroq shablon kod, o'qish oson, Stream/kolleksiya API'lar bilan tabiiy ishlaydi. Faqat functional interface'ga tayinlanadi.
?Functional interface nima?
Aynan bitta abstract metodi bo'lgan interfeys (default/static metodlar sanalmaydi). @FunctionalInterface annotatsiyasi kompilyatorni tekshirishga majburlaydi. Misollar: Runnable, Comparator, Predicate, Function.
?Predicate, Function, Consumer, Supplier farqi?
Predicate<T>: T → boolean (filtr). Function<T,R>: T → R (o'zgartirish). Consumer<T>: T → hech narsa (iste'mol, masalan print). Supplier<T>: hech narsa → T (ishlab chiqarish). Kirish/chiqish shakliga qarab tanlanadi.
?Lambda va anonymous class farqi?
Lambda qisqaroq, alohida .class fayl yaratmaydi (invokedynamic orqali), this tashqi class'ga ishora qiladi (anonymous'da o'ziga). Anonymous class bir necha metodli interfeys/abstract class uchun ham ishlaydi, lambda — faqat functional interface.
