Event loop

JavaScript bitta ipda ishlaydi, lekin tarmoq so‘rovlari, taymerlar va tugma bosishlari bir-birini bloklamaydi. Sehr — event loop: call stack, Web API’lar va ikki navbat (microtask va macrotask) o‘rtasidagi aniq qoidalar. JS suhbatlarining №1 savoli — "bu kod qanday tartibda chiqaradi?". Bu moduldan keyin siz javobni taxmin qilmaysiz, hisoblaysiz.

02

Qoidalar — bir sahifada

🔁 Bitta aylanish (tick)

1) Stack bo‘shaguncha joriy vazifa (skript yoki 1 ta macrotask) bajariladi. 2) Barcha microtask’lar bajariladi — jarayonda qo‘shilganlari ham. 3) Brauzer kerak bo‘lsa render qiladi (rAF → style → layout → paint). 4) Navbatdagi bitta macrotask olinadi.

⚡ vs ⏳

Microtask: Promise .then/catch/finally, await davomi, queueMicrotask, MutationObserver. Macrotask: setTimeout/setInterval, UI hodisalari (click, input), MessageChannel, fetch/XHR callback’lari (Web API tugagach).

🎯 Node.js’da farqi
Node’da ham event loop bor (libuv), lekin fazalari boshqacha: timers → pending → poll (I/O) → check (setImmediate) → close. process.nextTick — microtask’lardan ham oldin bajariladi. Brauzerdagi qoidani bilish frontend uchun yetarli.

05
Suhbat savollari
?Event loop nima va qanday ishlaydi?›
Bitta ipli JS’ni asinxron qiladigan mexanizm. Call stack bo‘sh bo‘lganda, avval microtask navbatidagi hamma vazifalar bajariladi, keyin brauzer render qilishi mumkin, so‘ng macrotask navbatidan bittasi olinib stack’ga qo‘yiladi — va takrorlanadi. Asinxron ishlarning o‘zi (taymer, tarmoq) brauzer/OS tomonidan bajariladi; ular tugagach callback navbatga qo‘yiladi.
?Microtask va macrotask farqi?›
Microtask’lar (Promise callback’lari, await davomi, queueMicrotask) joriy vazifa tugashi bilan, keyingi macrotask va render’dan oldin, navbat bo‘shaguncha bajariladi. Macrotask’lar (setTimeout, UI hodisalari, I/O) — har aylanishda bittadan.
?setTimeout(fn, 0) nega darhol ishlamaydi?›
0 — minimal kechikish; callback macrotask navbatiga tushadi va faqat stack bo‘shab, barcha microtask’lar tugagach bajariladi. Brauzerlar ichma-ich taymerlarni ≥4 ms ga cheklaydi, fon tablarda ≥1 s.
?Promise.then va setTimeout — qaysi biri oldin?›
Promise.then — microtask, har doim oldin (agar ikkalasi bir vaqtda navbatga qo‘yilgan bo‘lsa).
?await qanday ishlaydi event loop nuqtai nazaridan?›
await’gacha bo‘lgan kod sinxron bajariladi. await funksiyani to‘xtatadi va boshqaruvni chaqiruvchiga qaytaradi; kutilgan Promise tugagach davomi microtask sifatida navbatga qo‘yiladi. Ya’ni await — "shu yerdan keyingi qismni .then ichiga o‘ra" degani.
?Uzoq sinxron hisob-kitob nimaga olib keladi?›
Stack band — event loop aylanmaydi: kliklar, render, taymerlar kutadi, sahifa "muzlaydi" (Long Task, INP yomonlashadi). Yechim: bo‘laklash (setTimeout, scheduler.yield), Web Worker, yoki hisobni backend’ga o‘tkazish.
