Zamonaviy Java.

Java 8'dan keyin til juda o'zgardi: record, var, sealed, pattern matching, yangi switch, text block, virtual thread. Bu modul — "ortda qolgan" hamma narsani eski → yangi jonli taqqoslash bilan yopadi.

01

Versiyalar xaritasi

Java har 6 oyda chiqadi, har 2 yilda LTS (uzoq qo'llab-quvvatlanadigan). Ishda odatda LTS: 8 → 11 → 17 → 21. Versiyani bosing.

03
sealed + pattern matching switch

    
sealed — "bu interfeysni faqat shu klasslar amalga oshirishi mumkin". Kompilyator hamma variantni biladi, shuning uchun switch to'liqligini tekshiradi. Shaklni tanlang, keyin bir tarmoqni o'chirib ko'ring.

    

      

        
Doira(r=2)

        
Kvadrat(4)

        
To'rtburchak(3×5)

      

      

        sealed interface Shakl permits Doira, Kvadrat, Tortburchak {}

        double yuza(Shakl s) {

          return switch (s) {

            case Doira d      -> Math.PI * d.r() * d.r();
            case Kvadrat k    -> k.t() * k.t();
            case Tortburchak t -> t.a() * t.b();
          };
}
        
error: the switch expression does not cover all possible input values — Tortburchak tarmog'i yo'q

      

      

      

      
Doira tanlandi → case Doira d tarmog'i ishladi. d — avtomatik cast qilingan o'zgaruvchi (instanceof + cast kerak emas).

    

    

      
Eski usul vs yangi

      
// Java 8: instanceof + cast + if zanjiri, default unutilsa — jim xato
if (s instanceof Doira) { Doira d = (Doira) s; return Math.PI * d.getR() * d.getR(); }
else if (s instanceof Kvadrat) { ... }

// Java 16: pattern matching instanceof
if (s instanceof Doira d && d.r() > 0) { return Math.PI * d.r() * d.r(); }

// Java 21: record pattern — ichini ochib oladi
case Tortburchak(double a, double b) when a == b -> "aslida kvadrat";
case Tortburchak(double a, double b) -> a * b;

05
Virtual thread (21): 10 000 so'rov, ter to'kmasdan

    
Platform thread = OS thread (og'ir, ~1MB stek, mingtasi chegara). Virtual thread = JVM boshqaradigan yengil thread (millionlab). I/O kutganda (baza, HTTP) virtual thread OS thread'ni bo'shatadi. 24 ta so'rov, har biri 60% vaqt bazani kutadi:

    

      

      

        
Platform thread pool (4 ta)
Navbatda: 24 · Tugadi: 0/24 · Vaqt: 0 ms

        
Virtual thread (har so'rovga bittadan)
Navbatda: 24 · Tugadi: 0/24 · Vaqt: 0 ms

      

      
Binafsha — CPU ish, chiziqli sariq — I/O kutish (thread bekor turibdi). Platform pool'da 4 tadan ortiq so'rov parallel yura olmaydi.

06
Suhbat savollari

    
?record nima? Qachon ishlatasiz, qachon yo'q?
Immutable ma'lumot tashuvchi: maydonlar final, canonical constructor, accessor'lar, equals/hashCode/toString avtomatik. DTO, API request/response, Map kaliti, natija juftliklari uchun. JPA Entity uchun emas (mutable holat, no-arg constructor, proxy kerak). Extend qilib bo'lmaydi, lekin interface implement qiladi; compact constructor'da validatsiya.


?sealed nima beradi?
Ierarxiyani yopadi: permits ro'yxatidan tashqari hech kim implement qila olmaydi. Kompilyator hamma variantni bilgani uchun pattern-switch to'liqligini tekshiradi (default kerak emas), yangi variant qo'shilsa hamma switch kompilyatsiya xatosi beradi — domen modelini xavfsiz qiladi (masalan TolovHolati: Kutilmoqda/Tasdiqlandi/RadEtildi).


?var qachon zararli?
Tip o'ng tomondan ayon bo'lmaganda: var x = service.process(); — o'quvchi tipni bilmaydi. var null bo'la olmaydi, lambda/array initializer bilan ishlamaydi. Faqat lokal o'zgaruvchi (maydon, parametr, return emas). Kod o'qilishini yaxshilasagina ishlating.


?Virtual thread va platform thread farqi?
Platform thread — 1:1 OS thread, ~1MB stek, yaratish qimmat, mingtalar chegara. Virtual thread — JVM'ning yengil thread'i (bir necha yuz bayt), millionlab yaratish mumkin; I/O'da bloklanganda carrier OS thread'ni bo'shatadi (unmount). Foyda: I/O-og'ir serverlar (har so'rovga bitta thread modeli). Foyda yo'q: CPU-og'ir ish. Tuzoq: synchronized ichida I/O — pinning (21'da), ReentrantLock ishlating.


?Java 8'dan 17/21'ga ko'chishda nimalar sinadi?
Ichki API'larga kirish yopilgan (--add-opens kerak bo'lishi mumkin), Java EE modullari (javax.xml.bind, javax.annotation) olib tashlangan — jakarta yoki alohida dependency, eski kutubxonalar (Lombok, ASM, Mockito) yangilanishi kerak, javax.* → jakarta.* (Spring Boot 3), Nashorn yo'q, CMS GC o'chirilgan.


?switch ifodasi va switch operatori farqi?
Ifoda qiymat qaytaradi (int x = switch...), -> sintaksisida fall-through yo'q va break kerak emas, to'liq bo'lishi shart (enum/sealed uchun default kerak emas), blokda yield. Eski operator — break unutilsa fall-through xatosi.


?Pattern matching for instanceof nima?
if (o instanceof Mijoz m && m.aktiv()) — tekshiruv + cast + o'zgaruvchi bitta qadamda. m 'flow scoping' bilan faqat tekshiruv true bo'lgan joyda ko'rinadi. Java 21'da record pattern: if (o instanceof Nuqta(int x, int y)) — ichini ochib oladi.


?Stream.toList() va Collectors.toList() farqi?
stream.toList() (16) — immutable (unmodifiable) List qaytaradi, null elementga ruxsat beradi. collect(Collectors.toList()) — amalda ArrayList (mutable), lekin spec bo'yicha kafolat yo'q. Keyin o'zgartirish kerak bo'lsa — Collectors.toCollection(ArrayList::new).
