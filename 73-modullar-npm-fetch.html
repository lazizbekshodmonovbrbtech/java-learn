03

fetch bilan Spring API’ga murojaat

http.js — kichik, lekin to‘liq wrapper
const BASE = import.meta.env.VITE_API_URL;          // "https://api.bank.uz"

export async function http(path, { method = "GET", body, signal } = {}) {
  const res = await fetch(BASE + path, {
    method,
    signal: signal ?? AbortSignal.timeout(10_000),
    headers: {
      "Accept": "application/json",
      ...(body && { "Content-Type": "application/json" }),
      ...(auth.token && { "Authorization": `Bearer ${auth.token}` }),   // Keycloak access token
      "X-Request-Id": crypto.randomUUID(),                                // tracing / idempotency
    },
    body: body && JSON.stringify(body),
  });
  if (res.status === 401) { await auth.refresh(); return http(path, { method, body, signal }); }
  if (!res.ok) {
    const problem = await res.json().catch(() => ({}));                  // Spring ProblemDetail
    throw Object.assign(new Error(problem.detail ?? res.statusText), { status: res.status, problem });
  }
  return res.status === 204 ? null : res.json();
}

🧭 Brauzer

SecurityConfig.java
@Bean
SecurityFilterChain api(HttpSecurity http) throws Exception {
    return http
        .cors(Customizer.withDefaults())                 // quyidagi bean'ni ishlatadi; preflight auth'dan oldin o'tadi
        .authorizeHttpRequests(a -> a.anyRequest().authenticated())
        .oauth2ResourceServer(o -> o.jwt(Customizer.withDefaults()))
        .build();
}

@Bean
CorsConfigurationSource corsConfigurationSource() {
    var c = new CorsConfiguration();
    c.setAllowedOrigins(List.of("https://app.bank.uz"));            // "*" EMAS
    c.setAllowedMethods(List.of("GET", "POST", "PUT", "DELETE"));
    c.setAllowedHeaders(List.of("Authorization", "Content-Type", "X-Request-Id"));
    c.setMaxAge(3600L);                                               // preflight 1 soat keshlanadi
    var src = new UrlBasedCorsConfigurationSource();
    src.registerCorsConfiguration("/api/**", c);
    return src;
}
🎯 CORS — xavfsizlik devori emas
CORS — brauzer qoidasi: boshqa sayt JS’i sizning API javobingizni o‘qiy olmasligi uchun. curl, Postman, server-server chaqiruvlar CORS’ni bilmaydi. Shuning uchun API autentifikatsiyasi (JWT) baribir shart. Lokal ishlashda CORS’dan qochish: Vite server.proxy — so‘rovlar bir origin’dan ketadi.

06

Suhbat savollari

?ES modullar va CommonJS farqi?›
ESM: import/export, statik tuzilma (build vaqtida tahlil qilinadi → tree shaking), asinxron yuklanish, live bindings, brauzer va Node’da standart. CommonJS: require/module.exports, dinamik, sinxron, Node’ning eski formati.
?Tree shaking nima?›
Bundler import grafidan ishlatilmagan export’larni aniqlab, yakuniy bundle’dan chiqarib tashlashi. ESM statik bo‘lgani uchun mumkin. Yon ta’sirli modullar ("sideEffects" package.json’da) ehtiyotkorlik talab qiladi.
?^1.2.3 va ~1.2.3 farqi?›
^ — major o‘zgarmaydi: ≥1.2.3 <2.0.0. ~ — minor o‘zgarmaydi: ≥1.2.3 <1.3.0. 0.x uchun ^ qat’iyroq: ^0.2.3 → <0.3.0. Aniq versiya — prefikssiz. Lock fayl haqiqiy o‘rnatilgan versiyani qotiradi.
?CORS nima va preflight qachon bo‘ladi?›
Cross-Origin Resource Sharing — brauzer boshqa origin’ga so‘rov yuborib, javobni JS’ga berishdan oldin server ruxsatini (Access-Control-Allow-* sarlavhalari) tekshiradi. Preflight (OPTIONS) — "oddiy bo‘lmagan" so‘rovlar oldidan: GET/HEAD/POST’dan boshqa metod, application/json Content-Type, Authorization kabi maxsus sarlavhalar.
?fetch va axios farqi?›
fetch — brauzerga qurilgan, Promise, HTTP xatolarda reject qilmaydi, JSON’ni qo‘lda parse, timeout — AbortSignal. axios — kutubxona: interceptor’lar, avtomatik JSON, xato status’da reject, eski brauzerlar, upload progress. Ko‘p Vue loyihalari axios’ni tanlaydi (87-modul).
?SPA’da JWT’ni qayerda saqlash kerak?›
Eng xavfsiz — BFF: token’lar serverda, brauzerda HttpOnly cookie. Aks holda — xotirada (localStorage emas), qisqa umrli access token + refresh (Keycloak silent SSO), qat’iy CSP va XSS’ga qarshi himoya.
