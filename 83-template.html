Template: HTML’ga mantiq qo‘shish

Vue shabloni — oddiy HTML, lekin maxsus atributlar (direktivalar) bilan: v-if, v-for, v-model, @click. Kompilyator ularni render funksiyaga aylantiradi. Bu darsda eng ko‘p xato qilinadigan joylarni jonli ko‘ramiz: v-if va v-show farqi, v-for’da :key nega muhim, v-model modifikatorlari va event bubbling.

02

v-for va :key — eng mashhur xato

Ikkala ro‘yxat bir xil ma’lumot. Har qatorga izoh yozilgan (bu DOM ichidagi holat — input qiymati). Rangli DOM# belgisi — qaysi haqiqiy DOM elementi ekanini ko‘rsatadi. "Boshiga qo‘shish"ni bosing va izohlar kimda qolganiga qarang.

:key="index"
:key="t.id"
Vue ro‘yxatni yangilaganda eski va yangi virtual tugunlarni key bo‘yicha juftlaydi. Key bir xil bo‘lsa — "bu o‘sha element" deb hisoblaydi va DOM’ni qayta ishlatadi.
TransferList.vue
<template>
  <ul>
    <!-- ❌ index o'zgaradi: boshiga qo'shilsa hammasi siljiydi -->
    <li v-for="(t, i) in otkazmalar" :key="i">…</li>

    <!-- ✅ barqaror, noyob identifikator (DB id, UUID) -->
    <li v-for="t in otkazmalar" :key="t.id">
      {{ t.kimga }} — {{ format(t.summa) }}
      <input v-model="t.izoh" />
    </li>
  </ul>
</template>
Qoidalar
:key — noyob va barqaror bo‘lsin (id). Math.random() — har renderda yangi key, ya’ni hamma element qayta yaratiladi. Index — faqat ro‘yxat hech qachon qayta tartiblanmasa va qatorlarda ichki holat bo‘lmasa. Va v-if bilan v-for bir elementda ishlatilmaydi (Vue 3’da v-if ustun) — filtrni computed’ga chiqaring.
03

v-model va modifikatorlar

v-model — bu shunchaki :value + @input. Modifikatorlarni yoqib-o‘chirib, summa maydoniga yozing va holatdagi qiymat turi qanday o‘zgarishini kuzating.

Hozir modifikator yo‘q: input qiymati doim string. summa + 100 → " 1500 100" (konkatenatsiya!).
v-model = syntactic sugar
<!-- yozasiz: -->
<input v-model.number.trim="summa" />

<!-- kompilyator aylantiradi (taxminan): -->
<input :value="summa"
       @input="summa = parseFloat($event.target.value.trim()) || $event.target.value" />

<!-- komponentda (Vue 3.4+): -->
<SummaInput v-model="summa" />   <!-- ichida: const model = defineModel() -->

06

Suhbat savollari

?v-if va v-show farqi? Qaysi birini qachon ishlatasiz?›
v-if elementni DOM’dan butunlay olib tashlaydi/yaratadi (komponent unmount/mount, hook’lar, ichki holat yo‘qoladi); boshlang‘ich narx arzon, almashtirish qimmat. v-show doim render qiladi, faqat display:none. Tez-tez almashadigan narsalar — v-show, kam o‘zgaradigan yoki ruxsatga bog‘liq bloklar — v-if.
?v-for’da key nima uchun kerak? Index’ni key qilsa nima bo‘ladi?›
Vue diff algoritmi eski va yangi tugunlarni key bo‘yicha juftlaydi. Index key bo‘lsa, boshiga qo‘shish/o‘chirish/saralashda index’lar siljiydi — Vue boshqa ma’lumotni eski DOM elementiga "patch" qiladi. Natija: input qiymatlari, fokus, komponent ichki holati, animatsiyalar noto‘g‘ri qatorda qoladi va keraksiz patch’lar ko‘payadi. Barqaror id kerak.
?v-if va v-for bir elementda ishlatsa bo‘ladimi?›
Tavsiya etilmaydi. Vue 3’da v-if ustun turadi, shuning uchun v-if ichida v-for o‘zgaruvchisi hali mavjud emas. Filtrlashni computed’ga chiqaring yoki tashqi <template v-for> ishlating.
?v-model ichkarida qanday ishlaydi?›
Input uchun :value + @input (checkbox — checked + change, select — value + change). Komponentda — modelValue prop + update:modelValue emit; Vue 3.4+ da defineModel() makrosi. Bir nechta v-model: v-model:title.
?v-html nima uchun xavfli?›
U satrni HTML sifatida qo‘yadi, escape qilmaydi — foydalanuvchi kiritgan matnda skript yoki onerror="…" bo‘lsa XSS. Faqat ishonchli yoki sanitize qilingan (DOMPurify) kontent bilan.
?.stop va .prevent farqi?›
.stop — hodisaning ota elementlarga ko‘tarilishini to‘xtatadi (stopPropagation). .prevent — brauzerning standart harakatini bekor qiladi (forma yuborish, havolaga o‘tish). Ular bir-biriga bog‘liq emas, birga ham ishlatiladi: @click.stop.prevent.
