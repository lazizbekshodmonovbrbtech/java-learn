String'lar chuqur

String — Java'da eng ko'p ishlatiladigan tip, va eng ko'p tuzoqli. Immutability, String pool, == vs equals va StringBuilder — bularsiz suhbatdan o'tib bo'lmaydi.

01

String o'zgarmas (immutable)

Eng muhim fakt: String'ni o'zgartirib bo'lmaydi. toUpperCase() yoki + qilganingizda eski String o'zgarmaydi — yangi String yaratiladi. Tugmalarni bosing va kuzating.

HEAP — String obyektlari
ism →"otabek"
Boshlang'ich: String ism = "otabek"; — bitta obyekt.
nega immutable?
Xavfsizlik (String pool bo'lishishi mumkin), thread-safe (bir vaqtda o'qishga xavfsiz), va HashMap kaliti sifatida ishonchli (hashCode o'zgarmaydi). Bu suhbatning sevimli savoli.
02

String pool — literal vs new

Java bir xil matnli literal'larni String poolda bir marta saqlaydi va qayta ishlatadi (xotira tejash). Lekin new String() majburan yangi obyekt yaratadi. Bu ==ning javobini o'zgartiradi.

Pool.java
String a = "Java";             // pool'dan
String b = "Java";             // AYNI pool obyekti
String c = new String("Java"); // MAJBURAN yangi Heap obyekti

a == b        // true  — bir xil pool obyekti
a == c        // false — c alohida Heap obyekti
a.equals(c)   // true  — mazmun bir xil ✓

StringBuilder — nega + sikllarda yomon

    
String immutable bo'lgani uchun, siklda + bilan matn yopishtirish har qadamda yangi obyekt yaratadi — sekin va xotira yeydi. StringBuilder bitta o'zgaruvchan buferdan foydalanadi. "1000 marta qo'sh"ni bosing.

Builder.java

      
// ❌ Yomon — har iteratsiyada yangi String
String s = "";
for (int i=0; i<1000; i++) s = s + i;  // 1000 ta obyekt!

// ✓ Yaxshi — bitta bufer
StringBuilder sb = new StringBuilder();

StringBuilder vs StringBuffer

      Ikkovi ham o'zgaruvchan. StringBuffer — thread-safe (sinxronlangan, sekinroq), StringBuilder — thread-safe emas (tezroq). Bitta thread'da — doim StringBuilder.

07
Suhbat savollari

    

      
?String nega immutable?
Uch sabab: (1) xavfsizlik va String pool'da bo'lishish mumkin bo'lishi uchun; (2) thread-safe — bir vaqtda o'qishga xavfsiz; (3) HashMap kaliti sifatida ishonchli, chunki hashCode hech qachon o'zgarmaydi. Har o'zgartirish yangi obyekt yaratadi.

      
?String s = "a" va new String("a") farqi?
Literal ("a") — String pool'dan olinadi, takrorlanuvchi literallar bir obyektni bo'lishadi. new String("a") — majburan Heap'da yangi obyekt yaratadi (pool'ga bormaydi). Shuning uchun == ular uchun false qaytaradi.

      
?Sikldа matn yopishtirish uchun nima ishlatasiz?
StringBuilder. String immutable bo'lgani uchun siklda + har qadamda yangi obyekt yaratadi (O(n²) ishlash). StringBuilder bitta o'zgaruvchan buferda ishlaydi (O(n)).

      
?StringBuilder va StringBuffer farqi?
Ikkovi o'zgaruvchan (mutable). StringBuffer — thread-safe (metodlari synchronized, sekinroq), StringBuilder — thread-safe emas, lekin tezroq. Bir thread doirasida doim StringBuilder tanlanadi.
