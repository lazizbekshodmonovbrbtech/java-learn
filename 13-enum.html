enum

Ba'zi qiymatlar cheklangan to'plamdan bo'ladi: hafta kunlari, buyurtma holatlari, to'lov turlari. enum aynan shu — nomlangan konstantalar to'plami. String o'rniga enum ishlatish xatolarni yo'q qiladi.

01

Nega enum? String'ning muammosi

Nega.java
// ❌ String bilan — xatolarga ochiq
String holat = "PAID";
holat = "paid";     // katta-kichik xato — bilinmaydi
holat = "PIAD";     // terish xatosi — kompilyator tutmaydi!

// ✓ enum bilan — kompilyator himoyalaydi
Holat holat = Holat.PAID;
holat = Holat.PIAD;  // ❌ kompilyatsiya xatosi — bunday konstanta yo'q!
asosiy foyda
enum bilan faqat ruxsat etilgan qiymatlar mumkin. Noto'g'ri qiymat kompilyatsiyadayoq tutiladi — String'da esa faqat ishga tushganda (yoki umuman) bilinadi. Bank holatlari uchun bu juda muhim.
02

Holat oqimi — jonli

Buyurtma holatlari enum bilan. Har konstanta o'z tartib raqamiga (ordinal) ega. Holatni bosing yoki "Keyingi bosqich"ni bosing — oqimni kuzating.

Holat.java
enum Holat { KUTILMOQDA, TOLANGAN, JONATILDI, YETKAZILDI }

// switch bilan — enum juda mos:
switch (holat) {
    case KUTILMOQDA -> System.out.println("To'lov kutilmoqda");
    case TOLANGAN   -> System.out.println("Tayyorlanmoqda");
    case YETKAZILDI -> System.out.println("Yakunlandi ✓");
}
03

Maydon va metodli enum

enum shunchaki nom emas — u to'liq class. Har konstanta maydon va metodlarga ega bo'lishi mumkin. To'lov turini bosing — uning komissiyasi va hisoblangan haqqi ko'rinadi (bank misoli).

TolovTuri.java
enum TolovTuri {
    CARD(1.0), CASH(0.0), WALLET(0.5);  // har biriga maydon

    private final double komissiya;   // foizda
    TolovTuri(double k) { this.komissiya = k; }  // konstruktor

    public double haq(double summa) {          // metod
        return summa * komissiya / 100;
    }
}
TolovTuri.CARD.haq(100000);  // 1000 so'm
04

Foydali metodlar

Har enum avtomatik shu metodlarga ega.

values()
barcha konstantalar massivi
valueOf("PAID")
matndan enum'ga
name()
konstanta nomi (matn)
ordinal()
tartib raqami (0 dan)
Metodlar.java
for (Holat h : Holat.values()) {   // hammasini aylanish
    System.out.println(h.name() + " = " + h.ordinal());
}
Holat h = Holat.valueOf("TOLANGAN");  // matndan (masalan bazadan)
ordinal'ga tayanmang
Bazaga ordinal() (0,1,2) ni saqlamang — enum tartibini o'zgartirsangiz yoki oraga yangi konstanta qo'shsangiz, eski ma'lumot buziladi. Nom (name()) yoki alohida kod maydonini saqlang.
05

Suhbat savollari

?enum nima va String'dan afzalligi?
Cheklangan nomlangan konstantalar to'plami. String'dan afzal: (1) faqat ruxsat etilgan qiymatlar — noto'g'risi kompilyatsiyada tutiladi; (2) switch bilan xavfsiz; (3) maydon/metod qo'sha oladi; (4) type-safe. Holatlar, turlar uchun ideal.
?enum'da maydon va metod bo'la oladimi?
Ha. enum aslida to'liq class — har konstanta obyekt kabi maydon (konstruktor orqali) va metodlarga ega bo'lishi mumkin. Masalan har sayyoraning massasi/radiusi, har to'lov turining komissiyasi.
?enum obyektlari nechta nusxada?
Har konstanta — bitta nusxa (singleton), JVM tomonidan bir marta yaratiladi. Shuning uchun enum'larni == bilan solishtirsa bo'ladi (aynan bir obyekt). enum — Java'da singleton yaratishning ham eng xavfsiz usuli.
?Bazaga enum'ni qanday saqlaysiz?
Nomini (name(), String sifatida) yoki alohida barqaror kod maydonini. ordinal() (tartib raqam) ni SAQLAMANG — enum tartibi o'zgarsa ma'lumot buziladi. JPA'da @Enumerated(EnumType.STRING) ishlatiladi (28-modul).
