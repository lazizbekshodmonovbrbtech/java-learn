02

ArrayList ichida — u qanday kengayadi

ArrayList ichida oddiy massiv bor. Massiv to'lganda ArrayList yangi, kattaroq massiv yaratib, hammasini ko'chiradi (1.5 baravar). Element qo'shing va kengayish paytini kuzating — bu nega "amortized O(1)" ekanini tushuntiradi.

size0
capacity4
kengayishlar0
Ichki massiv sig'imi 4. Element qo'shing — 5-elementda kengayish yuz beradi.
suhbatda
"ArrayList add() nima uchun O(1)?" — Ko'p hollarda shunchaki massivga yozadi (O(1)). Ba'zan to'lganda ko'chiradi (O(n)), lekin bu kamdan-kam bo'lgani uchun o'rtacha (amortized) O(1). Oldindan o'lcham bilsangiz — new ArrayList<>(1000) bilan ko'chirishlarni oldini olasiz.
03

Ikkovi List, lekin ichi butunlay boshqacha. ArrayList — yonma-yon massiv. LinkedList — bir-biriga bog'langan tugunlar (har biri keyingisiga ko'rsatadi).

06

Klassik tuzoq: ConcurrentModificationException

for-each bilan aylanayotganda kolleksiyani o'zgartirsangiz (remove) — dastur qulaydi. Bu boshlovchilarning eng ko'p uchraydigan xatosi.

CME.java
// ❌ Xato — aylanayotganda o'chirish
for (String s : list) {
    if (s.isEmpty()) list.remove(s);  // ConcurrentModificationException!
}

// ✓ To'g'ri — removeIf yoki Iterator
list.removeIf(String::isEmpty);

// ✓ yoki Iterator orqali
Iterator<String> it = list.iterator();
while (it.hasNext()) { if (it.next().isEmpty()) it.remove(); }
07

Suhbat savollari

?ArrayList va LinkedList farqi?
ArrayList — ichida massiv: indeks orqali kirish O(1), o'rtaga qo'shish O(n) (surish kerak). LinkedList — bog'langan tugunlar: indeks orqali kirish O(n), boshiga qo'shish O(1), ko'proq xotira. Amalda deyarli doim ArrayList.
?HashMap qanday ishlaydi?
Kalitning hashCode() dan bucket indeksini hisoblaydi, o'sha bucketda equals() bilan aniq kalitni topadi. Bir bucketga ko'p tushsa (collision) — zanjir (linked list), Java 8+ da 8 tadan oshsa daraxt (red-black tree). Load factor 0.75 dan oshsa bucketlar soni 2 baravar oshadi (rehash).
?HashSet ichida nima bor?
Aslida HashMap! HashSet elementlarni HashMap'ning kaliti sifatida saqlaydi (qiymat — bo'sh obyekt). Shuning uchun takrorsiz va O(1) — HashMap kalitlari takrorlanmaydi.
?HashMap va Hashtable / ConcurrentHashMap farqi?
HashMap — thread-safe emas, tez, null kalitga ruxsat. Hashtable — eski, butunlay sinxronlangan (sekin). ConcurrentHashMap — zamonaviy thread-safe, segmentli qulflash (tez). Ko'p thread'da — ConcurrentHashMap (22-modul).
