Graf: hamma narsa bog‘langan

Shaharlar va yo‘llar, do‘stlar tarmog‘i, hisoblar orasidagi o‘tkazmalar (firibgarlik zanjirlari!), mikroservislar bog‘liqligi, Maven kutubxonalari — bularning hammasi graf: tugunlar (vertex) va ularni bog‘lovchi qirralar (edge). Daraxt — grafning xususiy holi (sikl yo‘q). Bu darsda grafni xotirada saqlash va uni aylanib chiqishning ikki asosiy usulini ko‘ramiz.

01

Grafni qanday saqlash?

Bir xil graf — ikki xil ko‘rinish. Tugunni bosing.

Qo‘shnilik ro‘yxati (adjacency list)
Qo‘shnilik matritsasi
Ro‘yxat — xotira O(V + E), siyrak graflar (real hayotdagi deyarli hammasi) uchun. Matritsa — O(V²), lekin "A va B bog‘langanmi?" — O(1). 1 mln foydalanuvchili ijtimoiy tarmoq matritsasi 10¹² katak — imkonsiz.
Graf.java
Map<String, List<String>> g = new HashMap<>();
void qirra(String a, String b) {                 // yo‘nalishsiz
    g.computeIfAbsent(a, k -> new ArrayList<>()).add(b);
    g.computeIfAbsent(b, k -> new ArrayList<>()).add(a);
}
02

BFS: to‘lqin kabi — eng qisqa yo‘l

Tosh suvga tushganda to‘lqin doira bo‘lib tarqaladi: avval 1 qadamdagilar, keyin 2 qadamdagilar… Shuning uchun BFS (og‘irliksiz grafda) eng kam qirrali yo‘lni topadi. Raqamlar — boshlanishdan masofa.

Kirish:
BFS.java
  1. Map<String, Integer> bfs(String start) {
  2. Map<String, Integer> dist = new HashMap<>();
  3. Deque<String> q = new ArrayDeque<>();
  4. dist.put(start, 0); q.offer(start);
  5. while (!q.isEmpty()) {
  6. String u = q.poll();
  7. for (String v : g.get(u)) {
  8. if (!dist.containsKey(v)) { // birinchi marta ko‘rildi
  9. dist.put(v, dist.get(u) + 1);
  10. q.offer(v);
  11. }
  12. }
  13. }
  14. return dist;
  15. }
03

DFS: labirintda devor bo‘ylab

Bitta yo‘ldan iloji boricha chuqur boramiz, boshi berk bo‘lsa — orqaga qaytib (backtrack) boshqa yo‘lni sinaymiz. Rekursiya (yoki stek) bilan.

Kirish:
DFS.java
  1. void dfs(String u, Set<String> seen) {
  2. seen.add(u);
  3. for (String v : g.get(u)) {
  4. if (!seen.contains(v)) {
  5. dfs(v, seen); // chuqurroq
  6. }
  7. }
  8. // u ning hamma qo‘shnilari tugadi → orqaga
  9. }
04

Orollar soni: to‘rdagi graf

Xaritada 1 — quruqlik, 0 — suv. Nechta orol bor? Har bir katak — tugun, qo‘shni (yuqori/past/chap/o‘ng) kataklar — qirralar. Yangi 1 topilganda DFS bilan butun orolni "bo‘yaymiz".

Kirish:
Orollar.java
  1. int orollar(char[][] m) {
  2. int son = 0;
  3. for (int r = 0; r < m.length; r++)
  4. for (int c = 0; c < m[0].length; c++)
  5. if (m[r][c] == '1') { son++; boya(m, r, c); }
  6. return son;
  7. }
  8. void boya(char[][] m, int r, int c) {
  9. if (r < 0 || c < 0 || r >= m.length || c >= m[0].length || m[r][c] != '1') return;
  10. m[r][c] = '#'; // ko‘rildi
  11. boya(m, r + 1, c); boya(m, r - 1, c); boya(m, r, c + 1); boya(m, r, c - 1);
  12. }

05

Suhbat savollari

?Grafni qanday ifodalaysiz?›
Qo‘shnilik ro‘yxati (Map/List) — O(V+E) xotira, siyrak graflar uchun; matritsa — O(V²), zich graf yoki tez "bog‘langanmi?" tekshiruvi uchun; qirralar ro‘yxati — Kruskal kabi algoritmlar uchun.
?BFS nega eng qisqa yo‘lni topadi?›
U tugunlarni masofa tartibida ochadi: navbatda avval d masofadagilar, keyin d+1. Tugunga birinchi yetganimizda bu — minimal qirralar soni. Og‘irlikli grafda bu ishlamaydi — Dijkstra kerak (102-dars).
?Grafda nega visited kerak (daraxtda kerak emas edi)?›
Grafda sikllar bor — visited’siz bir tugunga qayta-qayta kirib, cheksiz aylanamiz. Daraxtda har tugunga yagona yo‘l bor.
?Orollar sonini qanday topasiz va murakkabligi?›
Har katakni aylanamiz, 1 topsak hisobni oshirib, DFS/BFS bilan butun orolni ko‘rilgan deb belgilaymiz. Har katak bir marta — O(R×C). Juda katta to‘rda rekursiya chuqurligi xavfli — BFS yoki aniq stek.
?Yo‘naltirilgan grafda sikl bormi?›
DFS uch rang bilan: oq (ko‘rilmagan), kulrang (stekda), qora (tugagan). Kulrang tugunga qirra — sikl. Yoki Kahn algoritmi: topologik saralashda hamma tugun chiqmasa — sikl bor (102-dars).
?Bank misolida graflar qayerda?›
O‘tkazmalar grafi: firibgarlik halqalari (sikl), pul yuvish zanjirlari (yo‘llar), mijozlar o‘rtasidagi bog‘liqlik (bog‘langan qismlar), mikroservislar chaqiruv grafi.
