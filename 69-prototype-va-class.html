Prototype va class

Java’da obyekt klassdan yaratiladi va metodlar klassda yashaydi. JavaScript’da klass tushunchasi yo‘q edi — har obyektning prototipi bor, topilmagan xossa prototipdan, u yerdan uning prototipidan qidiriladi. ES2015’dagi class — shu mexanizm ustidagi qulay sintaksis. Suhbatlarda "prototype chain’ni tushuntiring" — klassik savol.

01

Prototip zanjiri: xossa qanday topiladi

const kk = new KreditKarta("Otabek", 10_000_000). Xossani bosing — dvigatel uni qayerdan topishini kuzating.

Xossani bosing.
karta.js
class Karta {
  #pin;                                      // haqiqiy private (ES2022)
  constructor(egasi) { this.egasi = egasi; this.holat = "ACTIVE"; this.#pin = "0000"; }
  blokla() { this.holat = "BLOCKED"; }       // → Karta.prototype'da (barcha kartalar uchun BITTA)
  get info() { return `${this.egasi} · ${this.holat}`; }
  static turi = "debet";                     // → Karta funksiyasining o'zida
}

class KreditKarta extends Karta {
  constructor(egasi, limit) { super(egasi); this.limit = limit; }
  blokla() { super.blokla(); log("Kredit liniyasi ham muzlatildi"); }   // override
  foiz() { return 0.28; }
}
const kk = new KreditKarta("Otabek", 10_000_000);

05
Suhbat savollari
?Prototip zanjiri nima?›
Har obyektning ichki [[Prototype]] havolasi bor (Object.getPrototypeOf, eskicha __proto__). Xossa obyektning o‘zida topilmasa, dvigatel prototipdan, keyin uning prototipidan… null’gacha qidiradi. Yozish esa (odatda) obyektning o‘ziga bo‘ladi — prototipdagi xossani "soyalaydi" (shadowing).
?class va konstruktor funksiya farqi?›
class — asosan sintaktik qulaylik: ichida konstruktor funksiya va prototip metodlari. Farqlar: class’ni new’siz chaqirib bo‘lmaydi, ichida strict mode, metodlar enumerable emas, class e’loni TDZ’da (hoisting yo‘q), #private va static bloklar faqat class’da.
?prototype va __proto__ farqi?›
Klass.prototype — funksiyaning xossasi: new bilan yaratilgan obyektlarning prototipi bo‘ladigan obyekt. obj.__proto__ (Object.getPrototypeOf(obj)) — obyektning haqiqiy prototip havolasi. new Klass() ⇒ obj.__proto__ === Klass.prototype.
?new operatori nima qiladi?›
1) Bo‘sh obyekt yaratadi, 2) uning prototipini Klass.prototype ga bog‘laydi, 3) konstruktorni this = o‘sha obyekt bilan chaqiradi, 4) konstruktor obyekt qaytarmasa — yangi obyektni qaytaradi.
?JS’da meros qanday ishlaydi?›
extends — ikki zanjir bog‘lanadi: Child.prototype.__proto__ === Parent.prototype (metodlar uchun) va Child.__proto__ === Parent (static’lar uchun). Konstruktorda this’dan oldin super() chaqirilishi shart.
?#private va closure bilan maxfiylik farqi?›
#maydon — tilga qurilgan, class’ga bog‘langan, tashqaridan va hatto Proxy orqali ham ko‘rinmaydi; har nusxada xotira tejamli (metodlar prototipda qoladi). Closure — funksiyalar har obyektda alohida yaratiladi.
