Meros va polimorfizm

OOP'ning haqiqiy kuchi. Class'lar bir-biridan xususiyat oladi (extends), va bitta chaqiruv har obyektda o'zicha ishlaydi (polimorfizm) — natija ish paytida (runtime) hal qilinadi.

01

Meros (extends) — xususiyat olish

Umumiy narsalarni bir marta ota-classda yozib, vorislar undan meros oladi. super ota-class'ga murojaat qiladi. Takrorlash yo'q.

Hayvonlar.java
class Hayvon {
    String nom;
    Hayvon(String nom) { this.nom = nom; }
    void ovoz() { System.out.println("..."); }
}

class Mushuk extends Hayvon {
    Mushuk(String nom) { super(nom); }  // ota konstruktorini chaqirish
    @Override
    void ovoz() { System.out.println("Meow"); }  // qayta yozish
}
@Override
@Override — ota metodini qayta yozayotganingizni bildiradi. Kompilyator imzoni tekshiradi — xato yozsangiz ogohlantiradi. Yozish shart emas, lekin doim yozing (xatolardan himoya).

03

Polimorfizm — natija runtime'da hal bo'ladi

Eng kuchli g'oya. Ro'yxatdagi hamma element Hayvon tipida ko'rinadi, lekin ovoz() chaqirilganda Java obyektning haqiqiy tipiga qarab javob beradi — bu dynamic dispatch. Kod hayvon turini bilmaydi, baribir to'g'ri ishlaydi. Kuzating.

for (Hayvon h : hayvonlar) {
    h.ovoz(); // tip Hayvon, lekin qaysi ovoz()?
}

06

Suhbat savollari

?Overriding va overloading farqi?
Overriding — vorisda ota metodini qayta yozish (bir xil imzo, runtime, polimorfizm). Overloading — bir class'da bir nomli turli parametrli metodlar (compile-time). Override — meros bilan, overload — parametrlar bilan.
?Polimorfizm qanday ishlaydi (dynamic dispatch)?
Havola tipi (Hayvon) faqat "shu metod bor" ligini kafolatlaydi. Aniq qaysi versiya ishlashi ish paytida obyektning haqiqiy tipiga qarab hal qilinadi (virtual method table orqali). Shu sabab bitta chaqiruv turli natija beradi.
?super nima uchun?
Ota-class'ga murojaat. super(...) — ota konstruktorini chaqirish (voris konstruktorining birinchi qatori bo'lishi mumkin). super.metod() — qayta yozilgan metodning ota versiyasini chaqirish.
?Java'da ko'p merosga (multiple inheritance) ruxsat bormi?
Class'lar uchun yo'q — bir class faqat bitta class'dan extends qiladi ("diamond problem"ni oldini olish). Lekin interface'lar orqali bir class ko'p interfeysni implements qila oladi (11-modul).
